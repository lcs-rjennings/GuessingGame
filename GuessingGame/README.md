# Guessing Game
 
The computer picks a random number from 1-100, and it's up to you to figure out what it is.
 
## How to play
 
1. Add or take away numbers until you have the number that you want to guess.
2. Press the guess button. The game will guide you to guess a higher or lower number.
3. The goal is to guess the secret number that the computer chose.
